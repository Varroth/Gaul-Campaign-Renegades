# Changelog — v2.5.2

**Compatibility patch** on 2.5.1, without balance changes.

- Per-instance optional bodyguard-side Leader choices for 15 squads; shared one-per-army named-Leader tokens, supporting 59 eligible pairs. Does not replace the app's native attachment feature.
- Preserved older Leader-side choices so previously saved rosters retain compatible IDs.
- Added optional once-per-army Bloodmarked Thralls / Bloodletters invocation planning control. Does not award free Bloodletters.
- Added four editable same-price weapon loadout presets for the two mortal units added in 2.5.1.
- Added 2.5.2 setup and quick-rule notes without altering earlier rules or enhancements.
- Improved standalone offline `.ros` roster formatter/checker: Lost Cohort, allies, legal paid leaders, Enhancement authorization, duplicate datasheets, named Character uniqueness, Warlord declarations and Thrall/Reaver specialist caps. Transport occupancy and table-time decisions remain manual.
- Compact-serialized the catalogue (reduced file size without removing selection options).
- 39,069 structural checks plus 8 Chromium fixture tests passed; in-app New Recruit tests still outstanding.
